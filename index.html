Part 9: Export Data to a CSV File

A CSV (Comma-Separated Values) file is one of the most common file formats used to exchange data.

We can export our current DataFrame into a CSV file. 

df.to_csv("employee_sales.csv", index=False)

This creates a file named: 

employee_sales.csv

The index=False option prevents Pandas from writing the DataFrame row numbers into the CSV file.

Part 14: Create a Bar Chart from Pandas Data

Instead of manually creating lists, we can create charts directly from the data contained in our DataFrame. 

plt.bar(df["Employee"], df["Sales"])

plt.title("Sales by Employee")
plt.xlabel("Employee")
plt.ylabel("Sales")

plt.show()

This is an important concept. The chart is now being generated directly from our business dataset.

Part 15: Create a Pie Chart

Pie charts can be used to visualize how categories contribute to a whole.

Create the following data:

labels = ["Apple", "Samsung", "Xiaomi", "BBK", "Others"]

share = [10.85, 7, 6, 10, 15]

Create the pie chart:

plt.pie(share, labels=labels)

plt.title("Company Share")

plt.show()

We can also display percentages: 

plt.pie(
    share,
    labels=labels,
    autopct="%1.1f%%"
)

plt.title("Company Share")

plt.show()

Part 16: Create a Donut Chart

A donut chart is similar to a pie chart but contains an empty center. 

labels = ["Apple", "Samsung", "Xiaomi", "Facebook", "Others"]

share = [10.85, 7, 6, 10, 15]

plt.pie(
    share,
    labels=labels,
    autopct="%1.1f%%",
    startangle=90,
    wedgeprops={"width": 0.4}
)

plt.title("Share of Companies")

plt.show()

The following argument creates the hole in the center: 

wedgeprops={"width": 0.4}

A smaller width produces a larger hole in the center of the chart.
