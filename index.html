Part 3: Create a Dataset

Imagine that you work for a company that wants to analyze employee sales performance.

Copy the following code into a new notebook cell:

data = {
    "Employee": ["Alex", "Maria", "Jordan", "Taylor", "Chris", "Morgan"],
    "Department": ["Sales", "IT", "Sales", "Marketing", "IT", "Sales"],
    "Sales": [12500, 8500, 15750, 11200, 9300, 18400],
    "Hours_Worked": [40, 38, 45, 42, 40, 47]
}

df = pd.DataFrame(data)

df

Running the cell should display the data as a table.

Question 2: What does the following line of Python code do? 
df = pd.DataFrame(data)

Part 4: Explore the Data

Pandas provides several commands that allow us to quickly examine a dataset.

Display the First Five Rows

df.head()

View Dataset Information

df.info()

View Descriptive Statistics

df.describe()

Determine the Dataset Size

df.shape
Command Purpose
df.head() Displays the first five rows.
df.info() Displays columns and data types.
df.describe() Calculates descriptive statistics.
df.shape Returns the number of rows and columns.

Part 5: Select Data

DataFrames allow us to retrieve specific columns instead of displaying the entire dataset.

Select One Column

df["Employee"]

Select Multiple Columns

df[["Employee", "Sales"]]
Question 3: What is the difference between selecting one column and selecting multiple columns?

Part 6: Filter the Data

One of the most powerful features of Pandas is the ability to filter data based on conditions.

Employees with More Than $10,000 in Sales

high_sales = df[df["Sales"] > 10000]

high_sales

Employees in the Sales Department

sales_department = df[df["Department"] == "Sales"]

sales_department

Part 7: Calculate Statistics

Total Sales

df["Sales"].sum()

Average Sales

df["Sales"].mean()

Highest Sales

df["Sales"].max()

Lowest Sales

df["Sales"].min()
Question 4: What are the total sales and average sales for the company?

Part 8: Create a Calculated Column

Management wants to know how many dollars in sales each employee generates for every hour worked.

Create a new column called Sales_Per_Hour:

df["Sales_Per_Hour"] = df["Sales"] / df["Hours_Worked"]

df

Round the values to two decimal places:

df["Sales_Per_Hour"] = df["Sales_Per_Hour"].round(2)

df
Question 5: Which employee has the highest sales-per-hour value?

You can use Pandas to determine the answer:

df.loc[df["Sales_Per_Hour"].idxmax()]

Part 9: Sort the Data

Sort employees from highest to lowest sales: 

df.sort_values(by="Sales", ascending=False)

Now sort employees by the number of hours worked: 

df.sort_values(by="Hours_Worked")

Part 10: Group the Data

Pandas can group records together to answer business questions.

Average Sales by Department

df.groupby("Department")["Sales"].mean()

Total Sales by Department

df.groupby("Department")["Sales"].sum()
Question 6: Which department has the highest total sales?

Part 11: Export Your Results

Pandas can also save DataFrames as files.

Export the completed dataset to a CSV file:

df.to_csv("employee_sales.csv", index=False)

The index=False option prevents Pandas from adding the DataFrame row numbers as another column in the CSV file.
